Ooki Grader 0.9.8 WindowsホストPC用アップデーター
======================================================

このフォルダーは、既にOoki Graderをポータブル版で設置した
WindowsホストPCを更新するためのものです。

【更新前に必ず行うこと】
1. 先生の操作と採点処理が終了していることを確認します。
2. バックアップを使う運用では、新しいバックアップが「検証済み」に
   なっていることを確認します。

バックアップを構成していないホストでも更新できます。その場合は
UPDATE WITHOUT BACKUP と入力します。データベース変更後に失敗した場合、
バックアップからの自動復旧はできません。

旧版にメンテナンスボタンがない場合は、UPDATE確認後にアップデーターが
サービスを停止し、オフラインでメンテナンスモードを安全に有効にします。

【更新開始】
1. 01-Update-OokiGrader-Host.cmd を右クリックします。
2. 「管理者として実行」を選びます。
3. ZIPと内部ファイルのSHA-256検査が完了するまで待ちます。
4. 表示される現行版、更新先版、データ、バックアップを確認します。
5. 正しければ UPDATE と入力します。

アップデーターは標準のインストール先とバックアップ先を自動検出し、
最新の検証済みバックアップを再検証します。データベース変更前に
失敗した場合は旧版を自動復旧し、旧版フォルダーも保持します。

【診断ログ】
  C:\OokiGrader-Setup\logs\host-update-<版>-<実行ID>.log
  C:\OokiGrader-Setup\logs\host-update-<版>-<実行ID>.result.json

【注意】
- 更新中にPCをシャットダウンしないでください。
- ZIP、checksums.txt、media-inventory.jsonを編集しないでください。
- エラー時に個別のDLLや操作マーカーを手作業で変更しないでください。
