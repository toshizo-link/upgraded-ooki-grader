Ooki Grader 0.9.1 WindowsホストPC用インストールメディア
========================================================

このフォルダーを、管理されたUSBメモリーなどでWindowsホストPCへ
フォルダーごとコピーしてください。

【事前に必要なもの】
1. Windows 11 Pro 64-bit
2. ローカル管理者権限
3. 64-bit PowerShell 7.4以降（未導入時は同梱MSIから導入されます）
4. 16 GiB以上の搭載RAM（ハードウェア予約領域は許容、32 GiB推奨）
5. NTFSのデータ保存先（165 GiB以上の空き）
6. 固定IPまたはDHCP予約
7. 暗号化済みの別バックアップ先

PowerShell 7が既に入っている場合の確認方法:
  pwsh --version

【インストール開始】
文字コード変換やPowerShellスクリプトの再保存は不要です。
1. 01-Install-OokiGrader-Host.cmd を右クリックします。
2. 「管理者として実行」を選びます。
3. PowerShell 7がない場合、公式MSIの署名とSHA-256を検査してインストーラーを開きます。
4. ZIPのSHA-256検査と展開が完了するまで待ちます。
5. バックアップ保存先を入力します。用意できていない場合はEnterだけを押します。
6. 画面に表示されるIP、校内CIDR、データ保存先、バックアップ先を確認します。
7. 内容を確認できた場合だけ、求められた確認語を入力します。

確認語:
  PRIVATE   信頼できる校内LANである
  ENCRYPTED バックアップ先が暗号化済みである
  UNSIGNED  管理された媒体から直接受領した配布物である
  RESERVED  ホストIPが固定またはDHCP予約済みである
  INSTALL   表示された全設定でインストールする

【正常終了の目印】
最終結果に次が表示されます。
  "state": "installed-and-verified"

【注意】
- 証明書警告を無視して続行しないでください。
- ZIPやSHA-256ファイルを編集しないでください。
- DLLをZIPから個別に削除しないでください。
- Prerequisites内のPowerShell MSIはMicrosoft公式配布物です。署名警告が出た場合は中止してください。
- このメディアは未署名です。管理された媒体での対面設置専用です。
- 失敗時はファイルを個別修復せず、表示されたエラーを保存してください。
