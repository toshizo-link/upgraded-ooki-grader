Ooki Grader 0.9.13 WindowsホストPC用インストールメディア
========================================================

このフォルダーを、管理されたUSBメモリーなどでWindowsホストPCへ
フォルダーごとコピーしてください。

【必須条件】
1. ネイティブx64の64-bit Windows
2. ローカル管理者権限
3. ローカルNTFSのデータ保存先
4. 使用可能なHTTPSポートと接続中の校内LAN
5. 正しい配布物と安全な証明書・パス構成

【推奨構成（満たさなくてもインストールは続行します）】
- 現行のWindows 11 Pro
- 16 GiB以上の搭載RAM（32 GiBなら余裕があります）
- データ保存先に165 GiB以上の空き容量

空きが既定の物理予約 5 GiB 未満でもインストールと修復は続行できますが、
空きを増やすか予約値を意図的に変更するまで答案アップロードは利用できません。

ホストにはWindows標準の64-bit Windows PowerShell 5.1だけが必要です。
.NET SDK、Node.js、PowerShell 7などの追加ランタイムをインストールする必要はありません。

【インストール開始】
1. 01-Install-OokiGrader-Host.cmd を右クリックします。
2. 「管理者として実行」を選びます。
3. ZIPのSHA-256検査が完了するまで待ちます。
4. IP、校内ネットワーク、データ保存先、バックアップ先は自動設定されます。
5. 画面の表示値を確認し、求められた確認語を入力します。

確認語:
  UNSIGNED  管理された媒体から直接受領した配布物である
  INSTALL   表示された全設定でインストールする

【再実行について】
展開後に中断しても、次回は同じZIPと完全一致する既存パッケージだけを
安全に再利用します。内容が違う既存フォルダーは上書きしません。

【診断ログ】
実行ごとのログと成功・失敗結果は次へ保存されます。
  C:\OokiGrader-Setup\logs\host-install-<版>-<実行ID>.log
  C:\OokiGrader-Setup\logs\host-install-<版>-<実行ID>.result.json
失敗時はこれらのファイルと画面の終了コードを設置担当者へ渡してください。

【正常終了の目印】
最終結果に次が表示されます。
  "state": "installed-and-verified"

【毎日の起動】
1. ホストPCの電源を入れます。Windowsへのサインインは不要です。
2. 1〜2分待ちます。Ooki GraderはWindowsサービスとして自動起動します。
3. 校内PCから https://ooki-grader.test/ を開きます。

開かない場合は、ホストPCで管理者PowerShellを開き、次を実行します。
  Get-Service OokiGrader.Host
  Start-Service OokiGrader.Host
「Running」になった後、30秒待ってブラウザーを再読み込みします。

【注意】
- 証明書警告を無視して続行しないでください。
- ZIP、checksums.txt、media-inventory.jsonを編集しないでください。
- DLLをZIPから個別に削除しないでください。
- このメディアが未署名の場合は、管理された媒体での対面設置専用です。
- 失敗時はファイルを個別修復せず、表示されたエラーを保存してください。
