# Ooki Grader 0.9.18 更新手順

## 更新するPCと手順

Ooki Graderを設置したホストPCで更新します。職員PCごとの更新作業は不要です。

1. 採点・答案の取り込みを終え、[更新用ZIP](https://github.com/toshizo-link/upgraded-ooki-grader/releases/download/v0.9.18/OokiGrader-0.9.18-Windows-Host-Update.zip)をダウンロードします。
2. ZIPを右クリックして「すべて展開」を選びます。展開先の `01-Update-OokiGrader-Host.cmd` を右クリックし、「管理者として実行」を選びます。
3. 更新先が `0.9.18` であることを確認し、画面の案内に従います。バックアップ未設定の場合の `UPDATE WITHOUT BACKUP` は、バックアップからのデータ復旧ができない条件で更新する確認です。判断できない場合は、その画面のまま開発担当へご連絡ください。
4. `Ooki Grader host update completed successfully.` と表示されたら、いつものURLを開き直します。古い画面が残る場合は `Ctrl + F5` で再読み込みします。
5. 名簿と過去の採点結果が開けることを確認します。保存済みのAPIキーは引き続き使用します。

更新中はPCの電源を切らず、採点・取り込みを行わないでください。エラーが表示された場合は、その画面の写真を添えてご連絡ください。

## 答案PDFの取り込み

複数ページのPDFをそのまま選択できます。「テストごとのアップロード」「受付中テストへ一括仕分け」のどちらも自動で1ページずつに分割します。ファイル名順と、各PDF内のページ順で処理します。

2ページのテストなら、生徒Aの1ページ目 → 2ページ目 → 生徒Bの1ページ目 → 2ページ目の順でスキャンしてください。分割後のページ名には元のPDF名とページ番号を表示します。生徒のまとまりを確認してから送信してください。各生徒の2ページ目も必要です。

1ファイル250 MB以下、合計1,000ページまで取り込めます。読み取れないPDFが含まれている場合、その選択分はまとめて追加を止め、対象ファイルを表示します。

## 合否の設定

テスト実施画面の「合格・不合格の判定」で、「合格にする最大ミス数」を設定して保存してください。例えば `4` なら **4ミスまで合格** です。結果画面・合否表・新しく作成する結果PDFに反映します。

部分正解・無解答・判読不能も、採点する1問につき1ミスです。空欄は合否基準未設定です。基準変更後は、作成済みの結果PDFを新しく作成し直してください。

## ひな形とSchool Manager

- ひな形保存時のデータ整形と、保存に失敗した後の再試行を改善しました。最終確認で止まっていたひな形は、もう一度作成をお試しください。保存エラーが残る場合は「生成状況で再試行する」から失敗した項目を再試行できます。生成された問題・正解・配点は原本と照合してください。
- School Manager設定時に `csrfToken` が見つからず停止する問題を修正しました。更新後のパッケージに含まれる `Set-OokiGraderSchoolManager.ps1` で設定を再実行してください。`-Enable` のみでは試行モードです。実配信は従来どおり送信先・内容を確認してから切り替えます。

10月18日、受領した2ページの問題PDFを実AIで読み取り、41問のひな形の生成・保存・再表示まで確認しました。正解候補の照合による要確認警告は残るため、生成した正解・配点を確認してから採点に使用してください。School Managerの実サービスへの送信は未確認です。
