# Windows更新検証（2026年9月7日）

## 結果

**0.9.2 → 0.9.9 は失敗。移行不具合を修正した 0.9.10 への更新は成功。**

Windows 11 Home x64 のローカルテストPCに、8月18日時点の配布物0.9.2を新規導入した。
架空の生徒・公開済みテンプレート・答案・確定済み採点結果を作成して更新を検証した。
最終状態は Windowsサービス `OokiGrader.Host` が0.9.10で稼働中、自動起動設定、
HTTPS正常、メンテナンス解除済み、DB整合性正常、移行マーカーなし。

## 発見した不具合と修正

0.9.9の移行 `20260827223000_0024_QuestionHierarchy` が、既存の公開済み問題に
新しい階層列を補完する際、`trg_published_question_no_update` に拒否された。
Windowsイベントログには SQLite Error 19: `published_template_content_is_immutable` が記録された。
0023までは適用され、0024で失敗したため、アップデーターは旧バイナリを起動せず停止状態を保持した。

修正では、0024のトランザクション内で階層列を補完する間だけ該当更新トリガーを外し、直後に復元する。
既存の問題文・配点・回答・教員メモ・公開版ハッシュは保持する。
AIメモや定型ルーブリックの整理は下書きに限定する。
公開済み・旧版扱い・廃止済みの各状態について、移行の往復と変更禁止制約の復元をテストに追加した。

不具合を含む0.9.9の配布物は比較用に保持し、修正した配布物には0.9.10を付与した。
先方へ渡す更新用パッケージは0.9.10を使用する。

## バックアップと検証範囲

このPCはBitLocker未暗号化であり、アプリ内バックアップの暗号化確認条件を満たさない。
条件を偽って有効化せず、サービス停止中のデータ一式をAES-256-GCMで暗号化した。
復号鍵は同じWindowsユーザーのDPAPIで保護し、アーカイブと鍵のACLを制限した。
各ファイルの復号後ハッシュ・SQLite整合性・外部キー整合性を確認し、実際に旧版へ復元した。
これは今回のテスト用の独立した復元手段であり、アプリ標準のバックアップ／自動復旧の合格証跡ではない。
更新時はその違いを明示する `UPDATE WITHOUT BACKUP` モードを使用した。

実際の生徒情報やAPIキーは使用していない。Gemini/OpenRouter接続・AI精度評価は未実施。
既存の架空答案PDFから最初の2問だけをテスト用採点基準に登録した。
原紙の氏名はデモ素材の表記であり、登録生徒への対応は手動で指定した。
教室の別PCからの接続、負荷試験、PC全体の再起動、実データの更新は検証範囲外。
